# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-09-08

First release.

- Transactional email: `sendEmail`, `sendEmailWithTemplate`, `sendBatch`, `sendBatchWithTemplates`
- Templates: list, get, create, update, delete
- Bounces: list with filters, get, dump, activate, delivery stats
- Messages: outbound/inbound search and details
- Stats: overview, sends, bounces, opens, clicks, spam
- Server details and per-stream suppressions
- `PostmarkException` carrying Postmark's `ErrorCode` and error body
